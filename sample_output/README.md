# Sample Output Directory

When you run `python generate_sample.py`, the generated promotional MP4 video will be written to this folder as:

```
sample_output/sample_video.mp4
```

### Video Specifications
- **Container**: MP4
- **Video Codec**: H.264 (libx264)
- **Audio Codec**: AAC
- **Resolution**: 1280x720 (720p HD, 16:9 widescreen)
- **Frame Rate**: 24 fps
- **Duration**: 20 - 40 seconds (dynamically synchronized to speech)
